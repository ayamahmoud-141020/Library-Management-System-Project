
# Library Management System

## Overview
The **Library Management System** is my graduation project for the DEPI Scholarship, a 6-month program focused on .NET Full Stack Development. This project demonstrates my expertise in both front-end and back-end development using **ASP.NET Core**, and it highlights key functionalities like book management, user authentication, and role-based access control.

## Features
- **User Registration & Authentication**: Secure user registration and login system.
- **Role-Based Access Control**: Different access levels for users, including admin and regular users.
- **Book Management**: Admins can add, update, and delete books.
- **Search & Borrow**: Users can search for available books and borrow them.
- **Return System**: Users can manage and track borrowed books and return them on time.
- **Dashboard**: Personalized dashboards for admins and users.

## Technologies
- **ASP.NET Core**: For building the server-side of the web application.
- **Entity Framework**: For database management and data handling.
- **SQL Server**: Used for storing data.
- **HTML/CSS/Bootstrap**: For the front-end design and responsiveness.
- **JavaScript/jQuery**: For client-side interaction and dynamic UI.
